# Website Viewer 1.0.0

## Highlights

- Local thumbnail grid for reviewing large URL lists.
- Import from pasted text, `.txt`, `.csv`, `.json`, or bookmarks `.html`.
- Automatic status checks, page titles, screenshot previews, progress estimates, and provider-aware throttling.
- Manual review workflow with valid/invalid decisions, selection tools, tags, filtering, sorting, and exports.
- No project storage: lists, decisions, screenshots, and metadata are cleared when the session ends.
- Local/private network targets are blocked by default for safer URL-list handling.
- The local server shuts down automatically a few minutes after all Website Viewer browser tabs are closed.

## Download

Use `Website-Viewer-v1.0.0.zip` from the GitHub release assets. Extract the zip, then open `README-FIRST.txt`.

## First Launch

Users need Node.js 18 or newer from https://nodejs.org/. The first launch installs dependencies and the browser used for screenshots, so it can take a few minutes.

## Known Limits

Some websites intentionally block automated browsers or render differently in screenshots. Use Reload or Open window when a preview looks blank, blocked, or incomplete.
