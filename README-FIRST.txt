WEBSITE VIEWER - START HERE

Website Viewer runs on your own computer. It does not upload your URL lists,
review decisions, screenshots, or metadata to a third-party service.

First-time setup:

1. Install Node.js 18 or newer from https://nodejs.org/ if it is not already installed.
2. Extract the Website Viewer release zip to a normal folder, such as Desktop or Documents.
3. Start the app:
   - Windows: double-click "Start Website Viewer.bat"
   - macOS: right-click "Start Website Viewer.command", then choose Open
   - Linux: run "./start-viewer.sh"

The first launch can take a few minutes because it installs the app packages
and the browser used for screenshots. Keep the launcher window open while using
Website Viewer. When you close all Website Viewer browser tabs, the local server
will shut down automatically after a few minutes.

Daily use:

1. Paste URLs into Add URLs, or import a .txt, .csv, .json, or bookmarks .html file.
2. Click Load list.
3. Wait for previews to populate.
4. Mark each site valid or invalid.
5. Export results from the button at the bottom left.

If a preview is blank, solid-colored, or blocked by the site, use Reload or
Open window to inspect it in your normal browser.
